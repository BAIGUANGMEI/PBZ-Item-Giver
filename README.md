# PBZ Item Giver · 藏物阁

基于 **UE4SS** 开发的《影之刃零》物品管理模组。进入游戏后按 **F7** 打开「藏物阁」，搜索物品、查看持有数量，并获取、减少或移除所选物品。

**当前版本：0.5.1** · 作者：[BAIGUANGMEI](https://github.com/BAIGUANGMEI)

## 下载

下载 [PBZItemGiver-0.5.1.zip](./PBZItemGiver-0.5.1.zip)，解压后按下方说明安装。请下载这个模组压缩包，而不是 GitHub 的整个仓库源码包。

## 功能

- **游戏内中文面板**：按 F7 开关，支持分类筛选，以及中文、英文名称或物品 ID 搜索。
- **物品详情**：查看名称、类别、ID、当前持有数量、说明和名称来源。
- **按需获取**：普通材料和普通消耗品每次可获取 1–99 个；装备及特殊物品限 1 件，并检查重复获取状态。获取装备后不会自动装备。
- **减少与移除**：减少指定数量，或清空当前选中的一种物品；操作前显示确认窗口。
- **本地目录**：随包提供 790 项物品记录，打开面板和更新列表只读取本地目录，不会自动发放物品。目录不代表全游戏物品覆盖。
- **记忆之花管理（实验性）**：可选择同步移除同一朵完整记忆之花及其关联花瓣，详见下方说明。

## 安装

### 前置条件

- 已安装《影之刃零》，并有能够正常加载本作 Lua 模组的 **UE4SS 适配环境**。
- 本压缩包包含模组脚本和 ModMenu 菜单框架，**不包含 UE4SS 加载器**。
- 游戏版本和 UE4SS 适配情况会影响可用性；本项目未提供适用于所有版本的兼容性保证。

### 安装步骤

1. 关闭游戏。首次使用或更新前，备份游戏存档；更新时也建议备份旧模组文件。
2. 解压 `PBZItemGiver-0.5.1.zip`。
3. 找到游戏当前使用的 UE4SS 目录，将解压得到的 `Mods` 文件夹合并到该目录。随包原说明中的安装布局为 `<游戏目录>\platform\steam\ue4ss\`；如果你的 UE4SS 位于其他位置，请以实际加载目录为准。
4. 确认安装后的结构如下，避免多套一层文件夹：

```text
<UE4SS目录>/
└─ Mods/
   ├─ PBZItemGiver/
   │  ├─ enabled.txt
   │  ├─ catalog.csv
   │  └─ Scripts/
   │     ├─ main.lua
   │     ├─ game.lua
   │     ├─ domain.lua
   │     ├─ text.lua
   │     └─ presentation.lua
   └─ shared/
      └─ ModMenu/
         ├─ ModMenu.lua
         └─ LICENSE
```

5. 保留随包的 `enabled.txt` 和 `catalog.csv`。如果已有自行维护的物品目录，请先备份再决定是否替换；其他模组也使用共享 ModMenu 时，请先备份现有框架文件。
6. 正常启动游戏，载入存档并进入可操作场景，按 **F7** 打开面板。

本包不含安装脚本，请按以上步骤手动安装。脚本替换后请重新启动游戏使其生效。

## 使用方法

1. 按 **F7** 打开「藏物阁」。主菜单或未进入存档场景时无法打开。
2. 输入名称或 ID，结合分类选择目标物品，核对详情中的名称与 ID。
3. 设置「操作数量」，点击「获取物品」。收集物或任务物品会先弹出确认提示。
4. 如需扣除库存，点击「减少数量」；如需清空所选物品，展开「移除物品」，点击「移除所选物品」，核对数量后确认。
5. 点击「更新列表与持有数量」可重读本地目录并更新所选物品的数量。背包显示没有及时变化时，关闭后重新打开游戏背包。
6. 再按 **F7** 关闭面板，进度通过游戏正常保存。

两次获取或库存修改操作请至少间隔 **2 秒**。模组没有「全部获取」或「清空背包」功能。

### 获取数量与重复限制

| 物品类型 | 获取规则 |
| --- | --- |
| 普通材料、普通消耗品 | 每次 1–99 个 |
| 武器、杀气兵器、饰品、药品 | 每次 1 件，当前已拥有时禁止重复获取 |
| 任务物品、记忆之花／花瓣、书籍／书页／信件、属性道具及游戏标记的剧情物品 | 每次 1 件；同时检查当前库存和历史获得记录 |

选择限单件物品时，操作数量自动回到 1。特殊物品即使消耗、合成或删除后库存为 0，也可能因历史获得记录而无法再次获取；花瓣还会检查所属完整花朵的历史记录。无法核实状态时，获取按钮会禁用。

本版不会自动清理旧版已添加的多余物品，也不会重置历史获得记录。

### 减少与移除的范围

- 支持普通道具类物品（包括材料、记忆之花、书页等），以及**未装备**的武器、杀气兵器。
- 已装备的武器需要先在游戏中卸下，再执行移除。
- 饰品、药品当前只支持获取，减少和移除按钮禁用。
- 「减少数量」不能超过当前持有数；「移除所选物品」清空所选这一种物品的库存。
- 确认后会再次核对数量；数量发生变化时中止操作，请重新确认。

**删除库存不等于撤销任务、收集或合成进度。** 游戏可能自动合成或去重，提交获取后数量不一定增加，请结合面板提示和游戏内状态判断。

### 记忆之花同步移除（实验性）

选择一朵记忆之花或一个花瓣，展开「移除物品」，勾选「同步取消当前收集（记忆之花，实验性）」，再点击移除。确认窗口会列出**该朵完整花和全部关联花瓣**的名称、ID 与数量变化。

此选项默认关闭，切换地图时复位，只影响「移除」，不影响「减少」。它只清零这一组花朵与花瓣的库存，不会重置历史获得记录、世界拾取点、任务或已消耗的效果，也不会清空所有记忆之花。清零后仍可能被历史记录限制再次获取。

实际收集界面和存档效果尚未完成实机验证，不能保证所有收集进度都回退。若操作中途失败，可能已修改部分库存，请检查提示与日志；模组不会自动回滚。

## 常见问题

**按 F7 没反应？** 先确认已经进入可操作的存档场景，再检查 UE4SS 是否正常加载，以及安装目录、`enabled.txt` 和共享 ModMenu 文件是否完整。

**提示目录缓存缺失或无效？** 从模组压缩包恢复 `Mods/PBZItemGiver/catalog.csv`。本版不会在缓存缺失时自动扫描游戏，也不会通过刷新目录发放物品。

**有些名称显示英文或内部名称？** 目录保留可获得的中文、英文及关联名称；缺少正式名称的条目使用内部名称。请结合 ID 和说明核对物品。

**获取按钮不可用？** 检查是否已经拥有该装备，或特殊物品是否曾经获得。无法读取相关状态时也会禁用获取。

**如何排查错误？** 查看 `<UE4SS目录>/UE4SS.log`，搜索 `[PBZItemGiver]`。可在 [Issues](https://github.com/BAIGUANGMEI/PBZ-Item-Giver/issues) 中提供模组版本、游戏／UE4SS 版本、物品 ID、复现步骤及相关日志片段。

## 更新与卸载

更新前先关闭游戏并备份旧文件，再替换对应模组文件。建议使用 0.5.1 替换 0.2–0.3.1；旧版目录刷新存在可能触发批量发放的问题。

卸载时，关闭游戏后移走 `Mods/PBZItemGiver` 文件夹。共享 `Mods/shared/ModMenu` 可能被其他模组使用，请确认后再移除。卸载不会自动撤销已获得的物品或恢复存档进度。
